# Fonts

Source Serif 4 (Adobe), under the SIL Open Font License 1.1 (https://openfontlicense.org), the typeface of Where They
Stand's hub and Where MPs Stand. These are the same files the hub serves (rj-mitchell/cio, `site/public/hub/fonts/`):
Latin and Latin Extended, upright and italic, weights 400 to 700. Served from this site, so visitors' browsers make no
requests to Google or anyone else.
